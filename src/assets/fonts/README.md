# Fonts

Both families are open source under the SIL Open Font License 1.1 and are served from this
site itself, never from a third party. The files are the Latin subsets published by
Fontsource (fontsource.org), which cover English and Spanish.

- **Barlow Condensed** (800 italic, 600 regular). Copyright 2017 The Barlow Project Authors
  (https://github.com/jpt/barlow).
- **Alegreya** (variable weight 400 to 900, regular and italic). Copyright 2011 The Alegreya
  Project Authors (https://github.com/huertatipografica/Alegreya).

The licence text: https://openfontlicense.org/open-font-license-official-text/

To change a font, replace the files here and update the `fonts` list in `astro.config.mjs`.
